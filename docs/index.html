ドコカワ

設変のSTEP、
どこ変わったかわからない。

困っていたので作りました。
STEPを2つ放り込むと、変更・追加・削除された部品が一覧で出ます。

ダウンロード（Windows / 無料）
ネット接続不要 · インストーラー版 / ZIP版を選べます
01 //

実際の画面です

これはモックではありません。同じ部品を修正した2つのSTEPを読み込んだときの実際の出力です。

ドコカワ — 差分チェック結果 + 形状比較ビュー
DIFF TABLE
変更・追加・削除を部品名で一覧表示。BBox差・体積差・面数も確認できる。
SHAPE COMPARE
変更前(R0)と変更後(R1)の形状を正面・上面・右側面で並べて表示。
CSV OUTPUT
差分結果をCSV/Excelで出力。設変記録としてそのまま使える。
// 上面図・右側面図
2方向の形状を並べて確認できます。
// 3Dモデル表示（マウスで回転・ズーム可能）
変更箇所をクリックすると3Dビューアに切り替わります。

表示内容は読み込んだSTEPのアセンブリ構成に応じて変わります。複数部品の場合は変更・追加・削除がまとめて一覧に出ます。

02 //

こういうとき

→ 「修正しました」とだけ書いてあるSTEPが戻ってきた
→ CADで両方開いて部品を一個ずつ見比べる。50部品あると時間がかかる
→ CADの比較機能、STEPには対応してない
→ 結局目視。見落としが怖いまま次工程に流す
これを解決します

STEPを2つ放り込むと、変更・追加・削除された部品が一覧で表示されます。CADを開かなくて済みます。

03 //

何ができるか

FUNC_01 STEP差分チェック
変更・追加・削除を一覧表示します。BBox差、体積差、面数の変化も確認できます。これがメイン機能です。
FUNC_02 形状比較ビュー
変更箇所の部品を正面・上面・右側面の3方向で並べて表示します。上の画像の通りです。
FUNC_03 3Dビューア
差分が出た部品をクリックするとブラウザ上で3D表示されます。回転・ズームも可能です。
FUNC_04 ローカル完結
外部通信はありません。STEPは処理後に消えます。社外秘でも使えます。

他にDfM警告（薄壁・深穴の自動検出）、仕様チェック（STEPとPDFの数値突き合わせ）もあります。作り始めたら増えました。
